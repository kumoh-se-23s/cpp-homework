1. 과제 코드 혹은 실습 코드들을 올릴때 미완성 코드를 main 브랜치에 올리지 말 것.
  -> main 브랜치는 이후 pull request 연습겸 매번 과제 혹은 실습이 끝날때 작업이 끝난 파일들로 생성
2. 자기 디렉토리 안에서만 작업할 것.
  -> 혹시나 남에거 건들여서 커밋이 꼬이면 골치가 많이 아픕니다.
3. gitignore나 리포지토리 루트에 무언가 만들어야한다면 꼭 카톡에 물어봐줄것.
  -> 보통 설정파일들이 메인에서 생기긴 하는데 개별 환경에서만 사용가능하도록
     이건 ignore로 최대한 막아볼 예정
